### ◆ [Ubique](https://github.com/NodalStudio/Ubique) — numerical computing at WebAssembly speed

[![JSR](https://jsr.io/badges/@nodalstudio/ubique)](https://jsr.io/@nodalstudio/ubique)
[![JSR Score](https://jsr.io/badges/@nodalstudio/ubique/score)](https://jsr.io/@nodalstudio/ubique)
[![npm](https://img.shields.io/npm/v/ubique?style=flat-square&color=050607)](https://www.npmjs.com/package/ubique)
[![License: MIT](https://img.shields.io/badge/license-MIT-050607?style=flat-square)](https://github.com/NodalStudio/Ubique/blob/main/LICENSE)

Vectors, matrices, linear algebra, statistics, time series and 40+ portfolio analytics — with the heavy lifting in Rust, compiled to WebAssembly. A complete rewrite of the original [ubique](https://github.com/maxto/ubique).

```ts
import * as ubique from "jsr:@nodalstudio/ubique";

const A = [[1, 2], [3, 4]];
const B = [[5, 6], [7, 8]];
ubique.mtimes(A, B);               // [[19, 22], [43, 50]]

const returns = [0.003, 0.026, 0.015, -0.009, 0.014, 0.024, 0.015, 0.066, -0.014, 0.039];
ubique.sharpe(returns, 0.02 / 12); // ≈ 0.6988
```

| vs. math.js · Mac mini M1 | Speed-up |
|---|---:|
| Matrix multiply · 500 × 500 | **13.05×** |
| Determinant · 50 × 50 | **26.04×** |
| Matrix inverse · 20 × 20 | **7.53×** |

<sub>Try it live: <a href="https://nodalstudio.github.io/Ubique/benchmark.html">interactive benchmark ↗</a></sub>
